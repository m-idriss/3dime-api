# Secure NVD scan setup

The original Maven security scan failed while initializing its NVD database without a valid NVD credential. The owner has now configured the secret securely, and a bounded GitHub Actions request using that credential returned HTTP 200. No response body, header or secret value was retained. The prepared workflow reads an Actions repository secret named `NVD_API_KEY` only in the credential check and scanner step. The Maven command contains the environment variable name, never the key value. OWASP's `nvdApiKeyEnvironmentVariable` parameter is used to avoid command-line disclosure. Do not enable Maven debug logging or publish environment files.

Owner setup is complete. For later rotation, request/activate a free key at https://nvd.nist.gov/developers/request-an-api-key and save it through https://github.com/m-idriss/3dime-api/settings/secrets/actions/new with the name `NVD_API_KEY`. Never paste the key into an issue, chat, source file, command argument, screenshot or workflow log. No credential is included in this change.
